# 迭代需求总结与工作量评估（2026-09-16 ~ 09-17）

分支：`qiugq-cron-0916` · 基线：dsh v0.1.0-rc.7 → v0.1.6-alpha.1 · 共 22 个提交

## 背景

dsh-web 是 DeepSeek Harness（dsh）的 Web 封装，用于 luoshu 服务端日志的智能分析。
本轮迭代完成四件大事：**平台升级与原生能力切换、工作区体系整合、分析体验增强（点击跳转）、
每日日志定时分析全链路闭环**，并配套部署加固与运维脚本。

### 说明

- **行号跳转是大头**（约占 30%）：dsh 前端不可控、无文档，渲染时序问题（刷新恢复后
  Button 丢失）需要逆向源码 + 多轮真机调试才能收敛，正常开发很难一次做对。
- **部署加固容易被低估**：5 个问题相互独立、横跨 dsh 内部多个子系统（插件加载树、
  权限服务、沙箱策略、LLM 配置），每个都需在服务器环境完整回路。
- 若由 1 名熟悉前端与 Linux 运维的全栈研发独立承担：约 **3 周（15 个工作日）**；
  前后端各 1 人协作可压缩至 **1.5～2 周**。
