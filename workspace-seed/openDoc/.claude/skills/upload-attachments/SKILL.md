# 用户上传的附件

## 核心规则

1. **用户上传的附件路径会出现在用户消息文本里**（形如
   `/data/.dsh/workspace-file-upload/<随机目录>/<随机目录>/<文件名>` 的绝对路径）。
   看到路径就直接用 Read/Grep 等工具读它，**不要在工作区里搜索附件**——
   附件按会话隔离，存在工作区之外的私有目录，工作区里永远找不到。
   路径里的目录名是随机的、按会话生成的，不需要也无法推测。
2. zip 压缩包上传后已自动解压，解压目录在压缩包同目录下同名文件夹；
   优先读解压后的目录，而不是压缩包本身。
3. 用户消息里没有路径 = 该会话没有附件（或用户删掉了），直接说明
   未收到附件，不要花时间在文件系统里找。

## 不要做的事

- 不要 `find /`、`ls ~/.dsh`、扫 `/data` 来"找附件"——其他会话的附件
  目录不归本会话使用。
- 不要向用户索要"上传目录"的位置；路径不在消息里就是没有。
